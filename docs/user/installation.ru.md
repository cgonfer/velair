Velair доступен в стандартном каталоге HACS. Установка вручную также возможна — например, если вы не используете HACS или хотите проверить конкретную сборку.

<a id="hacs"></a>
## HACS

1. Откройте HACS.
2. Найдите **Velair** среди доступных интеграций.
3. Откройте Velair и нажмите **Скачать**.
4. Перезапустите Home Assistant.
5. Перейдите в **Настройки > Устройства и службы**.
6. Добавьте интеграцию Velair.
7. Выберите сущности `climate.*`, которыми сможет управлять Velair.

Velair использует единицу температуры, выбранную в Home Assistant. При новой установке расписания, шаблоны, пороги комфорта, настройки Room Assist и значения по умолчанию для адаптивной подготовки создаются в этой единице. В настройках Velair единица отображается только для сведения; изменить её можно в Home Assistant.

При обновлении ранее опубликованной версии Velair, поддерживавшей только градусы Цельсия, может потребоваться сброс, если Home Assistant использует градусы Фаренгейта. Сначала прочитайте руководство [Единицы температуры и перенос данных](temperature-units.ru.md), чтобы при необходимости заранее экспортировать копию для справки.

<a id="manual-installation"></a>
## Установка вручную

Обычно установка вручную нужна только тем, кто не использует HACS или хочет проверить сборку из GitHub Actions либо GitHub Release.

Среди файлов выпуска есть архив `velair-custom-component-<version>.zip`. Распакуйте его так, чтобы появилась следующая папка:

```text
<home_assistant_config>/custom_components/velair
```

Если вы используете локальную копию репозитория, скопируйте:

```text
custom_components/velair
```

в:

```text
<home_assistant_config>/custom_components/velair
```

Перезапустите Home Assistant и добавьте Velair через **Настройки > Устройства и службы**.

<a id="github-actions-artifacts"></a>
## Артефакты GitHub Actions

Каждый успешный запуск CI загружает временные артефакты:

- `velair-custom-component`: полная папка `custom_components/velair` с интерфейсом, собранным во время этого запуска.
- `velair-lovelace-resource`: скомпилированные файлы `velair-card.js` для проверки ресурса Lovelace при расширенной ручной настройке.

Запуски для выпуска с тегом также прикрепляют ZIP-архивы к GitHub Release. Для обычного использования выбирайте HACS; эти артефакты подходят для проверки конкретного запуска рабочего процесса или установки вручную.

<a id="optional-lovelace-card"></a>
## Необязательная карточка Lovelace

Панель в боковой панели регистрируется автоматически. Карточку Lovelace добавлять необязательно.

Добавьте ресурс, предоставляемый интеграцией:

```yaml
url: /velair_frontend/velair-card.js
type: module
```

Затем добавьте одну или несколько карточек Velair. Каждая карточка использует те же данные серверной части и компоненты интерфейса, что и основная панель.

```yaml
type: custom:velair-card
view: overview-status
```

Поддерживаемые значения `view`:

- `climate`: состояние и управление одним устройством. Рядом с форсированным режимом и паузой можно дополнительно показать действие для разового возвращения домой. В существующих карточках это действие скрыто; новые конфигурации из окна выбора карточек включают его.
- `overview-status`: состояние планировщика и кнопки паузы, остановки и возобновления.
- `overview-boosts`: активные форсированные режимы.
- `overview-events`: ближайшие события.
- `overview-timeline`: события текущего дня на временной шкале.
- `overview-zones`: обзор зон.
- `active-setup`: текущий режим и профили с возможностью добавить элементы управления.
- `schedules`: полный редактор расписаний.
- `sensors`: настройки Room Assist и текущее состояние.
- `comfort`: настройки и состояние окружающих условий комфорта.
- `preconditioning`: настройки адаптивной подготовки и состояние локального обучения.
- `planned-return`: компактное управление разовым возвращением, количество источников присутствия в сохранённых настройках и временная шкала подтверждённого ухода. Если источники присутствия не сохранены, планирование возвращения сразу применяет настройки отсутствия; автоматическому еженедельному сценарию по-прежнему нужны эти источники.
- `diagnostics`: состояние работающей интеграции, ограниченная история, фильтры и экспорт отчёта о проблеме.

<a id="updating"></a>
## Обновление

После обновления Velair:

1. Перезапустите Home Assistant.
2. Выполните полное обновление страницы в браузере или перезагрузите приложение Home Assistant.
3. Убедитесь, что в разделе обслуживания настроек отображается ожидаемая версия интеграции.
