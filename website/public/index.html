Core workflow

Set the week. Change the routine when life changes.

Your weekly schedule stays as the baseline. Profiles, Modes, pauses and Boosts can change what should happen now without making you rebuild it.

Optional room sensor control

Room Assist makes the external sensor visible.

When a wall thermostat does not represent the room well, Room Assist temporarily adjusts its target using a separate temperature sensor. The graph shows the scheduled target, room reading, climate reading, applied target and current state.

Explicit stateAssisting, Holding, scheduled protection and other states explain the current decision.
Bounded correctionThe configured maximum delta limits how far Velair may adjust the device target.
No hidden sensor replacementThe thermostat still controls its own hardware; Velair changes only the target exposed through Home Assistant.

Adaptive Preconditioning

Start early when local history says the room needs it.

Velair can learn how long a managed zone usually takes to reach a scheduled target. Learning remains local, and the panel shows the planned lead time, learning status and observations behind it.

Adaptive behavior is optional and depends on sufficient observations from the selected room.

Before you install

A few practical limits.

Your climate integration still matters

Velair sends commands through the climate entities already in Home Assistant. The integration behind each entity determines which modes, targets and options it supports.

Local-first is not the same as offline

Schedules and decisions do not require a Velair account or cloud. A device exposed through a vendor cloud still depends on that connection.

Occupancy stays flexible

Use Profiles, Modes and pause actions from regular Home Assistant automations or the optional blueprints. Velair does not try to replace your presence logic.
